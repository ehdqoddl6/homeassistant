# 원달러 환율 알려줘

호출하면 기존 브리핑의 원달러 환율 센서 값을 읽고 Gemini가 금융뉴스 앵커의 존댓말 시황 브리핑을 생성해 거실 스피커로 재생한다.
[날씨 스크립트](../weather-briefing/README.md)와 같은 AI 생성·재시도·TTS 흐름이다.

## 파일과 적용

- [script.yaml](script.yaml): Home Assistant의 **새 스크립트 → YAML 편집기**에 전체 내용을 붙여 넣는다.
- 이미 등록했다면 기존 스크립트의 `ai_task.generate_data` → `data` → `instructions`만 수정본으로 교체한다.
- [수정 전 저장소 버전](history/2026-10-09-before-market-briefing.yaml)을 복구·비교용으로 보관한다.
- UI 단일 스크립트 매핑이다. 최상위 `script:`나 별도 스크립트 키로 감싸지 않는다.
- 이 저장소는 서버와 연결되어 있지 않으며, 파일을 읽는 상위 include는 없다. 실제 `scripts.yaml`에 직접 적용하려면 기존 매핑 구조에 맞는 별도 스크립트 키가 필요하다.
- 시간·요일 트리거는 없다. 기존 버스 스크립트처럼 음성 질의로 호출하려면 같은 호출 경로에 새 스크립트를 연결한다. 이름만으로 음성 호출 연결을 완료한 것으로 취급하지 않는다.

## 확인된 입력과 출력

| 항목 | 근거 |
| --- | --- |
| `sensor.yahoofinance_krw_x` | 기존 [아침 브리핑](../../automations/morning-briefing/automation.yaml)과 [일요일 브리핑](../../automations/sunday-briefing/automation.yaml)의 원달러 입력 |
| `ai_task.google_ai_task` | 기존 브리핑 및 사용자 제공 버스 스크립트 |
| `tts.google_ai_tts` → `media_player.geosil`, 음성 `Leda` | 기존 브리핑 및 사용자 제공 버스 스크립트 |

호출 시 센서에 저장된 값을 한 번 읽어 같은 실행의 재시도에 사용한다. 센서 강제 갱신이나 외부 시세 직접 조회는 하지 않는다.
특정 예문·고정 인사말·문장 수를 강제하지 않고 도입·연결·마무리를 자유롭게 구성하도록 요청한다.
1달러당 원화 금액을 중심으로 브리핑하며, 필요한 경우 환율의 의미에 관한 일반적인 설명만 짧게 덧붙인다.
누락·비정상 값은 추측하거나 0원으로 바꾸지 않도록 지시한다.
시세 기준 시각을 입력하지 않으므로 실시간·당일 마감 가격이라고 단정하지 않도록 한다.
현재 값 하나로 전일 대비 등락·강세/약세·높고 낮음·변동성을 판단하거나 국제금융 뉴스를 지어내지 않도록 한다.
환전·투자 권유나 은행 현찰·송금 환율 설명도 추가하지 않는다.

AI 생성은 최대 3회 시도하며 실패 사이에 2초를 기다린다. 매번 응답을 초기화하고 비어 있지 않은 문자열만 TTS로 전달한다.
생성이 모두 실패하면 고정 안내를 요청한다. TTS 오류는 재시도하지 않는다.
`mode: single`은 스크립트 실행 중 중복 호출을 막으며, 음성 재생 완료나 다른 스크립트의 재생을 관리하지 않는다.

## 검증과 운영 적용

- 로컬 YAML 문법·중복 키·단일 스크립트 구조·기존 엔티티 4개 재사용 검사 통과.
- 날씨 스크립트와 재시도·응답 검사·TTS 설정 일치 확인. 문서 상대 링크 17개와 변경·추가 파일 5개의 공백 검사 통과.
- Home Assistant 구성 검사·Jinja 렌더링·실제 센서 및 AI 응답·음성 호출·TTS 청취: 미검증.
- 2026-10-09 시황 브리핑 문체 변경: `instructions`만 변경하고 `exchange_rate` 입력을 보존했음을 정적으로 확인했다. 수정본·보관본 YAML과 링크 22개 검사도 통과했다. AI 생성이 모두 실패할 때의 고정 TTS 문구는 프롬프트 밖에 있으므로 기존 반말 안내를 유지한다.
- 운영 적용: 미적용. 로컬 YAML과 안내·작업 기록만 추가했다.
- 복구: 새 스크립트의 음성 호출 연결을 해제하고 해당 스크립트만 삭제한다.
- 문체만 복구하려면 보관한 수정 전 YAML의 `instructions`를 복원한다. 보관본은 사용자가 간소화한 프롬프트가 아닌 당시 저장소 버전이다.
