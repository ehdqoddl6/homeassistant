# 아침 브리핑

날씨·캘린더 일정·환율·시장 지표를 AI로 요약하고 거실 스피커에서 TTS로 읽는 자동화다.
사용자 제공 설정을 보관하고, 항목 나열처럼 들리는 말투를 자연스러운 문장으로 바꾸도록 `instructions`를 수정했다.

## 파일과 적용

| 파일 | 용도 | 상태 |
| --- | --- | --- |
| [automation.yaml](automation.yaml) | 자연스러운 음성 원고를 위한 instructions 수정본 | 로컬 문법·변경 범위 검증 완료, 운영 미적용 |
| [history/2026-10-04-before-instructions.yaml](history/2026-10-04-before-instructions.yaml) | 수정 전 사용자 제공 설정 | 복구·비교용 보관 |

두 파일은 UI의 **단일 자동화 YAML 편집기**에 넣는 형태다.
수정본을 적용할 때는 기존 자동화의 YAML 편집기에서 교체한다. 같은 브리핑 자동화를 중복 생성하지 않는다.
저장소에서 읽는 상위 include는 없으며 서버와 연결되어 있지 않다. 이 폴더를 통째로 include하지 않는다.
되돌릴 때는 수정 전 파일로 해당 자동화를 복원한다.

## 현재 설정

- 실행 시각: Home Assistant에 설정된 시간대 기준 월요일~토요일 07:03:30. 서버 시간대는 미확인이다.
- 입력: 사용자 제공 날씨 센서, 캘린더 5개, Yahoo Finance 센서.
- 생성: `ai_task.google_ai_task`, 최대 3회 시도.
- 출력: `tts.google_ai_tts` → `media_player.geosil`, 음성 `Leda`.
- 실패 안내와 `mode: single` 등 실행 구조는 사용자 제공 설정을 유지한다.

## instructions 변경

- 스피커가 읽을 원고만 생성하도록 하고 제목·목록·콜론을 통한 항목 나열을 금지했다.
- 날씨를 “지금 기온은 …도이고”처럼 조사와 서술어를 갖춘 문장으로 연결하도록 했다.
- 환율·지수·시장 심리·섹터·종목 사이를 짧게 연결하고, 등락 방향에 맞게 비교하도록 했다.
- 종목마다 동일한 문장을 강제하던 규칙을 제거했다. 유효한 가격과 등락률은 모두 말하되 문장 구조를 다양하게 쓰도록 했다.
- 후속 요청에 따라 개별 종목은 종목명·가격·등락률만 한 문장씩 짧게 전달하고, 기업 소개·뉴스·전망 등 추가 해설과 종목 부분의 재요약은 생략하도록 했다.
- 실제 수치를 지어내지 않도록 말투 예시는 자리표시자로만 작성했다. 입력에 없는 원유·금 설명 요구는 제거했다.
- 미확인 값은 추측하지 않고, 주말에는 출근 응원을 하지 않도록 명확히 했다.

## 검증과 미확인 항목

YAML 문법·중복 키·구조, instructions 외 설정 보존, Jinja 표현식 60개 보존과 문서 링크를 확인했다.
수정한 프롬프트의 실제 AI 출력과 TTS 청취 검증은 미실행이다.
다음 항목은 이번 instructions 수정 범위 밖의 후속 확인 사항이다.

- 이름은 “평일”이지만 트리거에 토요일이 포함되고 일요일은 없다. 일요일용 프롬프트 규칙은 현재 정기 실행으로는 사용되지 않는다.
- 모든 요일을 허용하는 시간 조건은 요일을 추가로 제한하지 않는다.
- 캘린더 조회 실패와 일정 없음이 같은 `등록된 일정 없음`으로 처리될 수 있다.
- 센서 누락 시 `default(0) | round(2)` 등 기존 숫자 템플릿의 처리와 실제 데이터 통화·갱신 시각을 확인할 필요가 있다. SK하이닉스 입력의 통화는 원문에 달러로 적혀 있다.
- AI 응답 검사는 `data` 존재 여부만 확인한다. 실제 빈 응답이나 TTS 실행 실패 시 처리는 별도 점검 대상이다.
