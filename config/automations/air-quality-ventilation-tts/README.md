# 공기질 나쁨 환기 음성 안내

안방 공기청정기의 초미세먼지가 높게 유지되면 거실 스피커로 환기를 안내하는 UI 자동화다.
환풍기를 자동으로 켜지는 않는다(사용자 선택: 음성 알림만).

## 파일과 적용

- [automation.yaml](automation.yaml): UI의 단일 자동화 YAML 편집기에 넣는 매핑이다.
- 운영 자동화: `automation/edit/1795178149178` (2026-11-20 HA UI에서 새로 저장).

## 동작

- 트리거: 초미세먼지가 35㎍/㎥를 넘은 상태로 10분 유지. 한국 초미세먼지 예보 등급의 "나쁨"(36 이상)에 맞춘 기본값이다.
- 조건: 거실 환풍기가 꺼져 있고, 08:00~22:00 사이일 때만 말한다. 밤에는 안내하지 않는다.
- `numeric_state` 트리거는 기준을 넘는 순간에만 실행되므로, 계속 높게 유지되는 동안 반복해서 말하지 않는다. 기준 아래로 내려갔다가 다시 넘으면 다시 안내한다.
- 환풍기를 켜면 기존 [환기팬 2시간 후 자동 끄기](../ventilation-auto-off/README.md)가 2시간 뒤 끈다.

## 확인된 엔티티

| 엔티티 | 근거 |
| --- | --- |
| `sensor.zhimi_sg_361561939_mb3_pm2_5_density_p_3_6` | Mi Air 3H(Master Room) "Environment PM2.5", Xiaomi Home 통합. HA 엔티티 목록에서 확인 |
| `fan.geosil_hoanpunggi` | h2m 거실 환풍기 |
| `tts.google_ai_tts` → `media_player.geosil`, `Leda` | 기존 기기 상태 TTS 자동화와 같은 설정 |

센서는 안방에 있어 거실 공기질과 다를 수 있다.

## 검증과 운영 상태

- 2026-11-20: HA UI에 저장. 시각 편집기에서 트리거 센서·환풍기 엔티티가 정상 표시되고, 조건 두 개가 현재 참으로 표시됐다.
- 실제 안내 발화: 미확인 (초미세먼지가 기준을 넘을 때 확인).
- 복구: HA 자동화 목록에서 비활성화하거나 삭제한다.
