# LG 세탁기 TTS 알림

기존 완료 알림과 예상 완료 시각 10분 전 거실 음성 안내 설정을 보관한다.
2026-10-04 사용자가 안내한 YAML 사용과 10분 전 알림 테스트 성공을 확인했다.

## 파일과 상태

| 파일 | 용도 | 상태 |
| --- | --- | --- |
| [completed.yaml](completed.yaml) | 사용자가 제공한 기존 완료 알림 | 내용 그대로 보관, 실제 동작은 이번 작업에서 검증하지 않음 |
| [before-complete-10min.yaml](before-complete-10min.yaml) | 예상 완료 10분 전 알림 | 사용 중인 설정, 테스트 성공 (사용자 확인) |

## 엔티티와 환경

| 항목 | 확인 상태 / 근거 |
| --- | --- |
| `event.setaggi_notification` | 사용자 제공 YAML의 세탁기 알림 엔티티 |
| `tts.google_ai_tts` | 사용자 제공 YAML의 TTS 엔티티 |
| `media_player.geosil` | 사용자 제공 YAML의 출력 대상 |
| 음성 `Leda` | 사용자 제공 YAML의 옵션 |
| `sensor.setaggi_remaining_time` | 제공한 YAML을 사용했다는 사용자 확인 기준. 실시간 상태·속성은 별도로 조회하지 않음 |
| Home Assistant 버전 / 설치된 LG 통합 종류·버전 | 미확인 |

## 적용 위치와 동작

두 YAML 모두 UI의 **단일 자동화 YAML 편집기**에 넣는 매핑 형태다.
현재 저장소에는 이 파일들을 읽는 상위 include가 없으며, 서버 설정과 연결되어 있지 않다.
자동화 목록 파일이나 패키지에 그대로 include하는 용도가 아니다.

10분 전 알림은 실제 남은 시간 센서가 완료 예정 날짜·시각을 나타내는 `device_class: timestamp`일 때 사용할 수 있다.
사용자는 제공한 YAML로 테스트 성공을 확인했다. 기존 완료 자동화와 별도로 사용한다.
센서가 숫자나 기간 문자열이면 해당 형식에 맞는 다른 트리거가 필요하다.

`offset: "-00:10:00"`은 센서의 예정 시각보다 10분 먼저 실행한다.
예정 시각이 조정되면 실제 완료까지 남은 시간과 차이가 생길 수 있다.
알림 후 예정 시각이 다시 늦춰지면 재알림할 수 있으며, `mode: single`은 세탁 1회당 알림 1회를 보장하지 않는다.
트리거 시각에 Home Assistant가 정지되어 있거나 예정 시각 갱신으로 트리거 시각이 이미 지나면 알림을 놓칠 수 있다.

기존 완료 YAML은 이벤트 종류를 구분하지 않는 상태 트리거다.
해당 엔티티가 다른 알림도 제공하는지는 미확인이며, 필요하면 실제 `event_type`을 확인해 완료 이벤트만 처리하도록 후속 수정한다.

## 검증과 운영 적용

- 로컬 YAML 2개의 문법·중복 키·단일 자동화 구조와 문서 상대 링크 24개를 검증했다.
- Home Assistant 구성 검사, 에이전트의 실제 세탁·TTS 동작 검증: 미실행.
- 사용자 확인: 2026-10-04 “10분전 알람 테스트성공했어”. 실제 시간 트리거 검증인지 액션 수동 실행인지는 미확인이다.
- 사용자 설정 확인: 같은 날 “예제로 준거 맞아”라고 알려 제공한 YAML을 사용 중인 설정으로 기록했다.
- 에이전트의 서버 적용·재로드·재시작: 미실행.
- 사전 알림을 되돌릴 때는 추가한 10분 전 자동화만 비활성화한다.
