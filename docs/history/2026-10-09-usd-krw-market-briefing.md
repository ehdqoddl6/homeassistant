# 원달러 환율 시황 브리핑 문체 변경

- 작업일: 2026-10-09 (Asia/Seoul)
- 상태: 로컬 수정·정적 검증 완료 / 실제 원고·음성 확인 대기
- 운영 적용: 미적용
- 대상 환경: 환경 기록상 Core 2026.9.3 / Home Assistant OS. 현재 서버 상태는 조회하지 않음.
- 관련 파일: [원달러 환율 스크립트](../../config/scripts/usd-krw-briefing/README.md)
- 이전 기록: [원달러 환율 음성 안내 스크립트 작성](2026-10-08-usd-krw-briefing-script.md)

## 목적과 근거

사용자가 조회된 환율과 짧은 질문만 남긴 프롬프트를 제공하고, 특정 템플릿 없이 국제금융 시황 브리핑처럼 전달하도록 요청했다.
이에 `ai_task.generate_data`의 `instructions`를 경제 전문 앵커 역할과 차분한 방송체 존댓말로 변경했다.

## 변경과 선택 이유

- `config/scripts/usd-krw-briefing/script.yaml`: 고정 예문과 한 문장 제한을 제거하고, 도입·연결·마무리를 자유롭게 구성하도록 변경했다.
- `config/scripts/usd-krw-briefing/history/2026-10-09-before-market-briefing.yaml`: 수정 전 저장소 파일을 그대로 보관했다. 사용자 제공 간소화 버전의 원문은 아니다.
- 스크립트 README와 이전·전체 히스토리에 새 작업을 연결했다.

입력은 `exchange_rate` 하나를 유지했다. 시황 브리핑의 문체를 적용하되 국제금융 뉴스 조회 기능을 추가한 것은 아니다.
환율의 의미에 관한 일반 설명은 허용하고, 실제 당일 뉴스·등락·강세/약세·변동성·원인을 추측하지 않도록 했다.
누락 안내는 고정 예문 없이 짧은 존댓말로 요청한다. AI 호출이 모두 실패할 때의 고정 TTS `message`는 프롬프트 밖이므로 유지했다.
센서 값 조회, 재시도, 응답 검사, TTS 음성 `Leda`, 스피커와 실행 모드는 변경하지 않았다.

## 운영 반영과 복구

로컬 파일만 수정했다. 적용 시 기존 스크립트 YAML의 `instructions` 값만 교체한다. 상위 include는 추가하지 않았다.
되돌리려면 보관한 수정 전 YAML의 `instructions`를 복원한다.
프롬프트 수정 당시에는 서버 저장·스크립트 실행·Git 커밋·푸시를 수행하지 않았다.
이후 사용자 요청에 따라 `[feature] 환율 안내를 자유로운 시황 브리핑으로 변경` 메시지의 별도 커밋으로 게시를 진행한다. Git 게시는 Home Assistant 운영 적용과 별개다.

## 미확인 사항과 다음 작업

실제 원고가 정형화되지 않은 방송체로 생성되는지, 입력 범위를 지키는지와 TTS의 발성·억양은 확인하지 않았다.
현재 입력으로 실제 국제금융 뉴스나 전일 대비 시황을 확인할 수는 없다.
