- 운영 적용: 미적용
- 대상 환경과 버전: 사용자 제공 Home Assistant YAML, 설치 버전·서버 시간대 미확인

## 목적과 관찰

사용자가 일요일 브리핑 YAML을 제공하고 평일 브리핑처럼 자연스러운 텍스트가 나오도록 instructions 수정을 요청했다.
입력은 날씨와 원달러 환율이며, 원문에는 일정 데이터가 없는데도 일정을 안내하거나 없다고 말하라는 지시가 있었다.

## 1차 변경과 선택 이유: 구어체 instructions

- `config/automations/sunday-briefing/automation.yaml`: 제공된 YAML의 instructions만 수정했다.
- `config/automations/sunday-briefing/history/2026-10-04-before-instructions.yaml`: 수정 전 설정을 보관했다.
- `config/automations/sunday-briefing/README.md`: 목적, 엔티티, 적용 위치, 복구 방법, 검증 상태와 기록 링크를 남겼다.
- `config/automations/README.md`, `docs/history/README.md`, `README.md`: 자동화와 기록을 목록에 반영했다.

제목·항목명·콜론을 읽는 형식 대신 조사와 서술어를 갖춘 짧은 구어체 문장을 사용하도록 했다.
날씨를 자연스럽게 연결하고 실용적인 팁을 한마디 덧붙인 뒤, 환율은 한 문장으로 안내하고 휴일 인사로 마무리한다.
일정은 데이터가 없으므로 생략하며, 미확인 수치나 환율 등락·시간대별 예보를 추측하지 않도록 했다.
말투 예시에는 실제 값 대신 자리표시자를 사용했다.

적용 위치는 UI의 기존 일요일 브리핑 자동화 YAML 편집기다. 상위 include는 없으며 로컬 보관 파일이다.
트리거·요일·시각·센서 템플릿·재시도·TTS 설정과 description·task_name은 원문을 유지했다.

## 운영 반영과 복구

로컬 파일만 작성했으며 서버 적용, 자동화 실행, 스피커 재생은 수행하지 않았다.
사용자가 기존 일요일 자동화의 YAML을 수정본으로 교체해 적용한다.
복구 시 같은 폴더의 `history/2026-10-04-before-instructions.yaml`로 되돌린다.
아래 일정 조회 추가만 되돌릴 때는 `history/2026-10-04-before-calendar.yaml`을 사용한다.

## 미해결과 다음 작업

- 실제 생성 문장과 음성을 확인해 항목명 나열이나 부자연스러운 연결이 남는지 확인한다.
- 초기에는 일정 조회가 없어 일정 안내를 생략했다. 이후 사용자의 추가 요청에 따라 아래와 같이 조회를 추가했으며 실제 캘린더 응답은 미확인이다.
- 기존 응답 검사는 data 존재 여부만 확인한다. 빈 응답·TTS 실패 처리는 후속 점검 대상이다.

## 같은 날 후속 수정: 평일 브리핑의 일정 조회 추가

사용자는 “아침브리핑에서 일정 데이터값 가져오는 부분 추가해서 넣어줘”라고 요청했다.
이에 일정 안내 생략 대신 평일 브리핑에서 사용하는 캘린더 5개의 조회 액션을 일요일 브리핑에 추가했다.

- 일정 추가 전 구어체 수정본을 `history/2026-10-04-before-calendar.yaml`에 보관했다.
- 평일과 동일한 `calendar.get_events` 대상·조회 시작 시각·24시간 범위를 사용했다.
- 조회 응답 `calendar_events`를 빈 매핑으로 초기화하고, 제목·시작 시각·장소를 `schedule_text`로 정리했다.
- 대상 캘린더의 응답이 모두 정상이고 이벤트가 없을 때만 일정 없음으로 처리한다. 누락·잘못된 응답 형식은 조회 실패로 구분하며, 확인된 일정이 있는 부분 응답은 일정과 실패 안내를 함께 전달한다.
- instructions에 `[오늘 일정]` 입력을 추가하고, 날씨 다음에 일정을 자연스럽게 안내하도록 수정했다. 초기의 일정 생략 지시는 제거했다.
- description을 날씨·일정·환율로 맞추고 README와 전체 목록을 갱신했다.

일정 조회는 AI 재시도 루프 앞에서 한 번 수행하며 조회 가능한 일정의 제목·시작 시각·장소를 전달한다.
일요일 07:40:00 트리거, AI 재시도와 TTS 설정은 유지했다. 서버 적용과 실제 캘린더 조회는 수행하지 않았다.
