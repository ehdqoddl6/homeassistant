# 프로젝트 개요와 전용 스킬 초기 구성

- 작업일: 2026-10-03 (Asia/Seoul)
- 상태: 완료 (로컬 파일 검증)
- 운영 적용: 해당 없음
- 관련 블로그: 없음

## 목적과 근거

Home Assistant 구축기 작성, 커스텀 컴포넌트 연동, 자동화 YAML 등 설정 작업을 진행하고 히스토리를 계속 쌓는다는 사용자 요청에 따라 저장소의 기본 구성을 만들었다.
시작 시 저장소에는 `.git/`과 `.idea/`만 있었으며 실제 Home Assistant 설정은 없었다.

## 변경과 선택 이유

- `README.md`: 프로젝트 개요, 작업 범위, 파일 구조, 스킬 사용법
- `AGENTS.md`: 작업 시작 방법, 검증 수준 구분, 기록 규칙, 대화 문체
- `config/README.md`, `docs/environment.md`: 설정 관리 위치와 미확인 환경 항목
- `docs/history/`, `docs/templates/`, `blog/README.md`: 작업 기록과 구축기 작성 흐름
- `.gitignore`: 자격 증명, Home Assistant 실행 상태, 백업, 로컬 캐시 제외
- `.codex/skills/`: 설정, 연동, 블로그 작업용 스킬 3개
- `.agents/skills/`: 원본 스킬을 참조하는 탐색용 링크

실제 환경이 확인되기 전에는 작동한다고 가정한 자동화나 설치 구성을 생성하지 않았다.
스킬 본문을 중복 관리하지 않도록 프로젝트 로컬 원본과 탐색 경로를 연결한다.

## 검증

- 스킬 3개: Ruby YAML 파서로 frontmatter, 이름·설명 제약, UI 메타정보와 호출 예시 검사 통과
- 기본 `quick_validate.py`: 로컬 Python에 PyYAML이 없어 실행 실패. 패키지를 추가 설치하지 않고 위 형식 검사로 대체했으며, 기본 검증기가 통과한 것으로 취급하지 않음
- 문서 내부 링크 17개, 코드 블록 닫힘, 줄 끝 공백 검사 통과
- 탐색용 심볼릭 링크 3개가 원본 경로를 가리키는지 확인
- 설치한 파일 6개의 SHA-256이 검증한 원본과 일치함을 확인
- Git 제외 규칙: 민감·실행 파일 경로 11개 제외, 관리할 파일·스킬 경로 9개 추적 가능 확인

위 검사는 파일 형식과 연결 상태 확인이며, 새 세션의 자동 스킬 선택 동작을 실행해 검증한 것은 아니다.
Home Assistant 구성 검사와 기기 동작 확인은 실행 환경 및 설정 파일이 없어 대상이 아니다.

## 복구

이번에 생성한 문서·스킬·탐색 링크·`.gitignore`만 검토 후 되돌리면 된다.
기존 `.idea/` 내용과 운영 서버는 변경하지 않는다.
