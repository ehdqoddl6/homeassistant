# 아침 브리핑 보관과 자연스러운 instructions 수정

- 작업일: 2026-10-04 (Asia/Seoul)
- 상태: 로컬 수정·검증 완료 / 실제 음성 결과 확인 대기
- 운영 적용: 미적용
- 대상 환경과 버전: 사용자 제공 Home Assistant 자동화 YAML, 설치 버전·서버 시간대 미확인
- 관련 파일: [아침 브리핑 폴더](../../config/automations/morning-briefing/README.md)

## 목적과 관찰

사용자는 자동화별 폴더와 히스토리 보관을 요청하고 아침 브리핑 YAML을 제공했다.
이후 “온도: 몇도”처럼 항목을 읽는 방식이 자연스럽지 않다고 설명하고,
날씨와 주식·시황을 “오늘 온도는 몇도이고”처럼 이어서 말하도록 `instructions` 수정을 요청했다.

원문은 항목명과 값을 입력하고, 개별 종목마다 같은 문장 형식을 반드시 지키도록 지시했다.
실제 생성된 음성이나 텍스트는 제공되지 않았으므로 원인은 확정하지 않고, 관찰된 지시문을 개선했다.

## 변경과 선택 이유

- `config/automations/morning-briefing/automation.yaml`: 사용자 제공 YAML을 보관한 후 AI 생성 단계의 `instructions`만 수정했다.
- `config/automations/morning-briefing/history/2026-10-04-before-instructions.yaml`: 수정 전 설정을 복구·비교용으로 보관했다. 빈 줄의 불필요한 공백은 제거했다.
- `config/automations/morning-briefing/README.md`: 실행 구조, 적용 위치, 변경 내용, 미확인 항목과 기록 링크를 추가했다.
- `config/automations/README.md`, `docs/history/README.md`, `README.md`: 자동화와 기록을 목록에 연결했다.

스피커용 구어체 원고를 명시하고 제목·콜론·글머리표 출력 대신 완성된 문장을 사용하도록 했다.
날씨는 말투 예시로 안내하고, 주식은 가격과 등락률을 유지하면서 문장 구조를 다양하게 쓰도록 바꿨다.
환율·지수·시장 심리·섹터·종목 사이에 자연스러운 연결을 지시했다.
입력에 없던 원유·금 정보를 설명하라는 요구를 제거하고, 누락 수치를 추측하지 않도록 했다.
토요일에는 출근하지 않는다는 사용자 설정에 맞춰 주말 인사를 구분했다.

숫자나 투자 사실을 새로 추가하지 않았으며, 예시 문장의 값은 자리표시자로 작성했다.
센서 입력과 Jinja 표현식, 실행 요일·시각, 캘린더 조회, 재시도와 TTS 설정은 유지했다.
UI의 기존 단일 자동화 YAML 편집기에 적용하는 형식이며 로드용 상위 include는 없다.

프롬프트의 지시문을 바꾼 것만으로 실제 생성 문장이 항상 자연스러워졌다고 판정하지 않는다.
검증 결과는 로컬 파일 검사와 운영 결과를 구분한다.

## 운영 반영과 복구

로컬 파일만 수정했다. SSH 접속, 서버 파일 수정, 자동화 실행, TTS 재생을 수행하지 않았다.
적용하려면 기존 자동화 YAML 편집기에 수정본을 넣는다.
되돌릴 때는 보관한 `history/2026-10-04-before-instructions.yaml` 내용으로 해당 자동화를 복원한다.

## 미해결과 다음 작업

- 사용자가 적용 후 날씨·시장·종목 부분의 실제 생성 문장과 음성을 확인한다.
- 현재 트리거는 월요일~토요일이다. 일요일 프롬프트 규칙은 정기 실행되지 않으며, 요일 변경은 이번 요청에 포함되지 않아 유지했다.
- 캘린더 실패와 일정 없음 구분, 센서 누락 시 숫자 필터 처리, 입력 통화·데이터 갱신 시각, 빈 AI 응답 및 TTS 실패 처리는 후속 점검 대상이다.

## 같은 날 후속 수정: 개별 종목 설명 축약

사용자가 개별 종목에 대해서는 간단히만 말하도록 추가 요청했다.
`automation.yaml`의 instructions에 종목당 한 문장으로 종목명·가격·전일 대비 등락률만 전달하도록 추가했다.
기업 소개, 뉴스, 등락 원인, 전망, 투자 의견 등의 부연 설명과 종목 부분의 마무리 요약은 생략한다.
종목을 빠짐없이 다루는 규칙, 자연스러운 문장 연결, 누락 데이터 처리 규칙은 유지했다.
README에도 이 변경을 기록했다. 이번 수정은 로컬에만 반영했으며 실제 AI 출력과 TTS 청취는 미검증이다.
