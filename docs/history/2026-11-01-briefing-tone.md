# 브리핑의 개인 호칭과 반말 제거

- 작업일: 2026-11-01 (Asia/Seoul)
- 상태: 로컬 수정·정적 검증 완료
- 운영 적용: 미적용
- 대상 환경과 버전: [환경 기록](../environment.md)의 Home Assistant OS / Core 2026.9.3 (2026-10-04 사용자 제공 화면 기준). 현재 서버 상태와 설정 경로는 미확인.

## 목적과 관찰

자동화·스크립트의 음성 안내에서 여자친구 말투를 제거한다. 현재 배포 후보인 아침·일요일 브리핑 YAML은 개인 호칭과 반말을 원고에 요구했고, 날씨·환율 스크립트는 AI 생성 실패 시 같은 호칭을 고정 문구로 재생하도록 작성돼 있었다. 과거 `history/` YAML은 당시 상태를 보여 주는 비교·복구 자료다.

## 변경과 선택 이유

- [아침 브리핑](../../config/automations/morning-briefing/automation.yaml)과 [일요일 브리핑](../../config/automations/sunday-briefing/automation.yaml): AI 지시를 개인 호칭 없는 자연스러운 존댓말로 바꾸고, 반말 예시·일정 조회 실패 문구·고정 TTS 실패 문구를 같은 문체로 맞췄다. 센서, 일정, 트리거, 재시도, TTS 대상은 유지했다.
- [날씨](../../config/scripts/weather-briefing/script.yaml)와 [환율](../../config/scripts/usd-krw-briefing/script.yaml) 스크립트: AI 생성 실패 시 고정 TTS 안내에서 호칭과 반말을 제거했다. 기존 AI 프롬프트는 이미 존댓말이었다.
- 관련 자동화·스크립트 README에 이 기록을 연결했다. 이전 작업 기록과 보관용 YAML은 당시 사실을 보존했다.

네 YAML은 Home Assistant UI의 기존 자동화 또는 단일 스크립트 YAML 편집기에 넣는 형태다. 저장소에서 이 파일들을 읽는 상위 include는 확인되지 않았다.

## 운영 반영과 복구

운영 서버에는 적용하지 않았다. 적용 시 기존 UI 자동화·스크립트 각각에서 해당 YAML을 교체한다. 되돌릴 때는 이 작업 전 Git 버전의 네 YAML을 복원한다. 과거 `history/` YAML은 이 작업 직전 전체 상태가 아니므로 그대로 적용하지 않는다.

## 미해결과 다음 작업

실제 AI 출력에 호칭이나 반말이 섞이지 않는지, 실패 안내가 스피커에서 의도한 존댓말로 들리는지는 운영 적용 후 확인해야 한다. 현재 서버 설정과 적용 여부도 미확인이다.
