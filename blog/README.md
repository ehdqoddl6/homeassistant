# 구축기 글 관리

실제 [작업 기록](../docs/history/README.md)을 바탕으로 글을 작성한다.
글은 `YYYY-MM-DD-주제.md`, 필요한 공개용 이미지는 `assets/주제/`에 둔다.
아직 작성한 구축기나 발행한 글은 없다.

새 글은 [구축기 양식](../docs/templates/blog.md)을 참고한다.
확인되지 않은 경험이나 성공 결과는 만들어 넣지 않고 편집 메모에 남긴다.
설정 예시와 스크린샷에서 토큰, 주소, 개인 위치, 식별정보를 가린다.

| 작성일 | 글 | 상태 | 원본 작업 기록 | 발행 URL |
| --- | --- | --- | --- | --- |

초안 작성과 외부 발행을 구분한다. 발행을 수행하거나 사용자가 발행 결과를 알려준 경우에만 발행일과 URL을 채운다.
